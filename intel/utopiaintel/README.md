# Utopia Intel

Integrated from the `Myztikal125/utopiaintel` repository.

Sample scripts to parse pages from utopia-game.com.

Users can specify a URL endpoint and a key. The key is optional but is suggested to ensure control over who posts.

Both raw HTML and highlighted/copy-pasted data are sent. What you use depends on how you like parsing data.

See `example.php` to get started.

This component is intended to serve as the Utopia Nexus intel ingestion foundation.
