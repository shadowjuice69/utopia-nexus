Intel System Setup Guide

Nexus automatically collects enemy intel and sends it to the war dashboard as you browse Utopia. Setup takes under 2 minutes.

What Nexus Does
🔍

Auto-scrapes Intel

Captures enemy province data as you browse kingdom pages and the intel site.

📊

Feeds the Dashboard

All data flows automatically to the war dashboard — no manual entry.

🤖

AI War Analysis

AI ranks targets, assesses threats, and answers questions about your kingdom.

⚡

Kingdom Cycler

Auto-cycles through all 76 enemy kingdoms in ~25 minutes with one tap.

Setup Steps
1

Install Tampermonkey

Tampermonkey is a free browser extension that runs the Nexus script. Works on Chrome and Firefox.

Chrome Firefox

🦊 Firefox users: You can also install the official Utopia Nexus Intel extension directly from Mozilla Add-ons — no Tampermonkey needed.

2

Install the Nexus Script

Choose your install method. Tampermonkey users click the script link. Chrome extension users download the zip.

⚡ Tampermonkey Script 🧩 Chrome Extension v6.2

Chrome: extract the zip, go to chrome://extensions, enable Developer Mode, tap Load unpacked.

3

Browse Utopia as Normal

Visit these two sites while logged into Utopia. Nexus runs automatically in the background — you'll see a small status bar at the bottom of the page.

UTOPIA GAME

Kingdom pages, throne, military, ops results

utopia-game.com →

INTEL SITE

Full kingdom CSV stats — visit enemy kingdoms here. Nexus captures the data automatically when the CSV loads. You don't need to save the file — cancel the download if it appears.

intel.utopia.site →
4

Use the Kingdom Cycler (Optional)

First navigate to kingdom 1:1 so the cycler starts from the beginning and covers all kingdoms.

Go to Kingdom 1:1 →

Then tap ▶ Start Cycling in the top-left panel. It automatically scrapes all 76 enemy kingdoms while you leave the tab open — takes about 25 minutes.

Troubleshooting
?

Script not running?

Make sure Tampermonkey is enabled. Click the Tampermonkey icon in your browser toolbar — the script should show as active (green toggle).

?

No status bar showing?

Reload the Utopia page. If it still doesn't appear, try disabling and re-enabling the script in the Tampermonkey dashboard.
